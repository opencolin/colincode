01Claude Code2026

A coding agent in a box, one command away.

colin creates or resumes a sandbox on Luxor, starts your coding agent in tmux on the inference provider you picked, and puts you straight into it. Name your agents, switch providers without touching a config file, and never hit a paused box.

install.sh · macOS & Linux
$curl -fsSL https://colincode.org/install.sh | sh

installs colin into ~/.local/bin · needs the Luxor CLI (the tenki command) and jq · llms.txt

02Why it existsglue

The CLI has every primitive. This is the glue.

Create or resume

Every command routes through one function that creates a missing box, resumes a paused one and waits out a pending one. A paused box costs you a few seconds, never an error.

Survives everything

The agent runs in tmux inside the box. Close the laptop, lose the Wi-Fi, let the box pause: colin <agent> drops you back into the same conversation.

Your provider

Point any harness at Nebius, Boundless, Baseten, Friendli or OpenRouter from an arrow-key menu. Keys are asked for once, kept locally with mode 0600, and never pass on a command line.

05Usagecolin help

Three commands from zero to a running agent.

colin help
colin                        pick an agent (or create one) and jump into it
colin new [cli|web|harness]  create: terminal or web → harness → provider → model → size → volume → name
colin <harness> [action]     a harness: your agent for it, or a new one
colin <agent> [action]       a specific agent by name

up        (default)  create or resume the box, start the agent, attach
ssh                  same as up (attach to the running agent)
shell                plain shell in the box
run -- <prompt>      one-shot headless prompt
status               agent, provider, box state
provider             switch inference provider (and model)
model [id]           switch model
size [name]          box size; applies when the box is created
volume [GiB|none]    persistent volume at ~/work: add one, or drop it
url [off]            web UIs: a public Luxor preview link, or remove it
auth                 sign in / store the provider key
down | pause         pause the box (auto-resumed next time)
rm | stop | kill     terminate the box and forget the agent (--purge deletes the volume)

colin ls                     list agents and their boxes
colin pause --all            pause every agent's box
colin rm --all [--purge]     terminate every box and forget every agent
Sizes

small 2 vCPU / 4 GiB · medium 4 / 8 (default) · large 8 / 16 · xlarge 12 / 32 · xxlarge 16 / 64. A box is not resized in place: size applies on the next create.

Volumes

A persistent volume at ~/work (10, 25 or 50 GiB) that survives pause, rm and resizing. The agent starts there. A volume keeps its size for life, so pick generously.

Headless

colin nebius-codex run -- "fix the failing test" runs one prompt and exits, with the provider wired in. Toolkits take raw arguments: colin tinyfish run -- fetch content get https://…

06Pausing & configuration2h

Boxes pause by themselves and wake on your next command.

Pausing

Boxes are not sticky. Luxor pauses one two hours after it was created or last resumed, the workspace cap. The CLI has no idle-timeout flag, so the timer is the pause. Every colin command resumes a paused box first, and the timer starts again from the resume.

tmux and the agent's session survive it; /tmp and open TCP connections do not, so an agent paused mid-request retries when the box is back. For a job that must run unattended for longer, create the agent with COLINCODE_STICKY=1.

Environment
COLINCODE_HARNESSclaudeharness used when you omit one
COLINCODE_SIZEmediumdefault box size offered
COLINCODE_VOLUME_GB10default volume size offered (0 = none)
COLINCODE_DISK_GB20root disk
COLINCODE_IMAGE—a registry image for every harness without its own
COLINCODE_MAX_DURATION2hpause this long after each create or resume (Luxor's cap)
COLINCODE_PAUSE_RETENTION720hhow long a paused box is kept
COLINCODE_STICKY01 creates boxes that never pause by themselves
