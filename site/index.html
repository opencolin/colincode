Start a box

Three commands from zero to a running agent.

1

Install once

Run the one-liner. It puts colin on your PATH and checks for the tenki CLI and jq. Log in with tenki login if you haven't already.

2

Pick terminal or web, a harness, a provider, a size, a name

Run colin. Arrow-key menus walk you through terminal-or-web, the harness, the inference provider (the harness default, or Nebius, Boundless, Baseten, Friendli, OpenRouter), a model, the box size (2 vCPU / 4 GiB up to 16 vCPU / 64 GiB), a persistent volume at ~/work that outlives the box, and a name. Leave the name empty and you get the harness name on its default provider (claude, opencode-web) or <provider>-<harness> on a third-party one (nebius-codex).

3

Launch

The box is created (or resumed), the agent starts in tmux with the provider wired in, and you land inside it. For Claude Code on Anthropic, the first run opens Claude's sign-in over SSH, and the box is then one tap away on claude.ai/code. Detach with Ctrl-b d; colin <agent> drops you back in.

Why colin exists

The tenki CLI has every primitive. This is the glue.

Every subcommand routes through ensure_running(): it creates a missing box, resumes a paused one, waits out a pending one, and only then does what you asked.

Auto-pause, auto-resume

Boxes pause by themselves two hours after each create or resume, so a forgotten agent stops costing you. A paused box is resumed, a pausing box is waited out, a missing box is created. No more "sandbox not RUNNING" errors.

Lives in tmux

Agents run in a named tmux session, so SSH drops and sandbox pauses don't kill them. Detach with Ctrl-b d; colin claude drops you back in.

Remote Control

Claude Code boots with --remote-control, so the sandbox is one tap away in claude.ai/code or the mobile app.

Any provider, no config edits

Provider settings are sent into the box over ssh and sourced at launch. Switch provider or model with one command and the agent restarts on it. Nothing in the agent's own config is touched.

Inference providers

The harness default, or bring your own models.

Pick a provider when you create an agent, or switch later with colin <agent> provider. Keys are asked for once and kept in ~/.config/colincode/env.

Claude Code loses Remote Control on any third-party base URL; the menu says so next to each option. Where a provider has no Anthropic Messages API, a stdlib-only Python proxy embedded in colin runs in a second tmux session (claude-proxy) and translates /v1/messages, streaming and tool calls included, to /chat/completions. Codex uses the Responses wire API for custom providers, which all of the above expose.

Usage

One verb per thing you want.

colin help
colin                        pick an agent (or create one) and jump into it
colin new [cli|web|harness]  create: terminal or web → harness → provider → model → size → volume → name
colin <harness> [action]     a harness: claude, codex, opencode, pi, droid, grok, amp, prime-agent, tinyfish, anchor, hotdata, copilot, gemini, qwen, crush, goose, kimi, omp, adal, hermes, openclaw, opencode-web, open-webui, hermes-web, openclaw-web, durable-pi
colin <agent> [action]       a specific agent by name

up        (default)  create or resume the box, start the agent, attach
ssh                  same as up (attach to the running agent)
shell                plain shell in the box
run -- <prompt>      one-shot headless prompt
status               agent, provider, box state
provider             switch inference provider (and model)
model [id]           switch model
auth                 sign in / store the provider key
down | pause         pause the box (auto-resumed next time)
size [name]          box size, small (2/4) … xxlarge (16/64)
volume [GiB|none]    persistent volume at ~/work
url [off]            web UIs: a public tenki preview link, or remove it
rm | stop | kill     terminate the box and forget the agent (--purge: volume too)

colin pause --all            pause every agent's box
colin rm --all               terminate every box, forget every agent

colin ls                     list agents and their boxes
VariableDefaultMeaning
COLINCODE_HARNESSclaudeharness used when you omit one
COLINCODE_SIZEmediumdefault box size offered: small, medium, large, xlarge, xxlarge
COLINCODE_VOLUME_GB10default volume size offered (0 = none)
COLINCODE_DISK_GB20root disk (tenki recommends 20 for agents)
COLINCODE_MAX_DURATION2ha box pauses this long after each create or resume (tenki's cap)
COLINCODE_STICKY01 makes boxes that never pause by themselves
COLINCODE_IMAGEnonestart from a published registry image
Roadmap

Where this is going.

Every harness from agentcamp

Shipped

Twenty-one terminal agents (eight of them tenki's pre-built images) and five web UIs, the set proven in agentcamp, with its provider injector reused inside the box. Not here: QM (needs agentcamp's broker) and OpenUI (a build of agentcamp's own).

Inference providers

Shipped

Pick a provider and model per agent. Providers without an Anthropic API (Nebius) work with Claude Code through a translation proxy in the box. Next: more providers, and keys that never enter the box.

Sized boxes, persistent volumes

Shipped

Five box sizes from 2 vCPU / 4 GiB to 16 vCPU / 64 GiB, and a per-agent volume at ~/work that survives pause, rm and resizing.

Resume through a pause

Planned

Reopen a Claude session started in a sandbox even after the sandbox paused — the box wakes on demand and the session picks up where it left off.
